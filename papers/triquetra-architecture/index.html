The Triquetra Architecture

Why AI Governance Requires Mutually Constraining Tiers · Charter Architecture Series, Part 1 of 3

Shawn J. Ralph — Anti-Box Riot Collective  |  March 2026  |  DOI: 10.5281/zenodo.18896363
Abstract
Single-layer AI safety architectures face a tradeoff that can't be engineered away: make the filter aggressive and it blocks legitimate use; make it permissive and it allows attacks. No threshold resolves this. The underlying problem is the single layer itself. We describe the Triquetra Architecture, a three-tier governance system in which each tier has a distinct function and each constrains the others in specific, documented directions. Tier I (Sovereigna Firewall) handles adversarial pattern detection. Tier II (Harmonic Conscience) handles decision-time conscience evaluation. Tier III (Eve Protocol) handles identity continuity and behavioral drift detection. The constraint topology has two enforced edges and one implicit baseline edge. 55 tests pass across enforcement and integrity suites.
